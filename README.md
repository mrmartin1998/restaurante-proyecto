# Restaurante - Proyecto Final Front-End

🍽️ **Proyecto Final del Curso de Programación Front-End - Tokio School**

Web responsive para restaurante de vanguardia con sistema de reservas, carta digital, y páginas legales RGPD-compliant.

## 📋 Características

### Páginas Principales
- **Inicio**: Presentación del restaurante con platos destacados
- **Carta**: Menú completo categorizado
- **Especialidades**: Showcase de platos estrella
- **Menús Grupos**: Opciones para eventos con accordion interactivo
- **Reservas**: Formulario funcional con validación y envío real (FormSpree)

### Páginas Legales
- Política de Privacidad (RGPD compliant)
- Aviso Legal (LSSI-CE compliant)
- Política de Cookies

### Extras Implementados
- ✅ 29 imágenes reales optimizadas
- ✅ Enlaces a redes sociales en footer
- ✅ Páginas legales profesionales
- ✅ Banner de cookies con localStorage
- ✅ Formulario funcional con FormSpree
- ✅ Deploy en GitHub Pages

## 🛠️ Tecnologías

- **HTML5**: Estructura semántica
- **CSS3**: Variables, Flexbox, Grid, Mobile-first
- **JavaScript ES6+**: Vanilla JS (sin frameworks)
  - Fetch API para componentes dinámicos
  - LocalStorage para cookie consent
  - Validación de formularios (7 validadores)
  - FormSpree integration
